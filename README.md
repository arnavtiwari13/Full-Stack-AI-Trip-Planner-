# Full Stack AI Trip Planner

An AI-powered full-stack travel planning application that helps users
create personalized travel plans, manage trip preferences, and organize
their journeys.

## Features

- AI-powered itinerary generation
- Personalized travel planning
- User authentication
- Group trip planning
- Destination recommendations
- Budget planning
- Responsive React interface
- REST API backend
- MongoDB data storage

## Tech Stack

### Frontend
- React.js
- JavaScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB

### AI
- AI API integration for personalized travel recommendations
